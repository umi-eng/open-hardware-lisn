# Open Hardware Dual DC LISN

This is a line impedance stabilization network for measuring conducted emissions to aid in evaluating designs for EMC compliance. It's based on an existing design from Rhode & Schwarz, which only existed as Gerber outputs.

This design is intended as a development tool and not suitable for empirical compliance testing.
